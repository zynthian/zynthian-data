
This Pure Data patch, designed for use with the Zynthian open-source synth, utilizes an external 
object based on the open-source firmware of the Plaits Eurorack module.

The original Plaits module was developed by Mutable Instruments, whose open-source contributions 
have significantly influenced the world of modular synthesis.

Mutable Instruments is a registered trademark. This project is an independent derivative work 
and is not affiliated with or endorsed by Mutable Instruments. The name of the original module has not 
been retained, in accordance with their guidelines.

Special thanks to Javier Nonis for porting the original Plaits firmware into a Pure Data external object, 
making this patch possible.
